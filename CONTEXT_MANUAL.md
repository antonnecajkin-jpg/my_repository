## 🗂️ **ПАТТЕРНЫ ПУТЕЙ**

### **Windows → Docker маппинг:**
```

Windows: C:\Users\myb0o\airflow\.dbt\
Docker: /home/airflow/.dbt/ (нужно копировать)
```

### **Команды копирования файлов:**
```powershell
# Windows → Docker контейнер
docker cp "C:\путь\файл" имя_контейнера:/путь/в/контейнере/

# Создать папку в контейнере
docker exec имя_контейнера mkdir -p /путь/папки

# Выполнить команду в контейнере
docker exec -it имя_контейнера bash
```

## 🔧 **РЕШЕНИЯ ТИПОВЫХ ПРОБЛЕМ**

### **Проблема 1: "localhost не работает из контейнера"**
```
Решение: Использовать host.docker.internal
Пример: 
- Локально: jdbc:postgresql://localhost:5431/db
- Контейнер: jdbc:postgresql://host.docker.internal:5431/db
```

### **Проблема 2: "Нет прав/папки в контейнере"**
```
Решение: Создать папку и скопировать файлы
Команды:
docker exec контейнер mkdir -p /нужный/путь
docker cp локальный_файл контейнер:/нужный/путь/
```

### **Проблема 3: "Установка в контейнере не сохраняется"**
```
Решение: Добавить в Dockerfile или использовать volume
Вариант A: Изменить docker-compose.yml
Вариант B: Создать скрипт инициализации
```
